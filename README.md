# Журнал регистрации приказов по видам деятельности

Сетевое веб-приложение (Python + Flask + SQLite): журналы приказов
«Опека», «Нуждаемость», «Профилактика», справочники сотрудников и видов
приказов, ролевой доступ, загрузка PDF-сканов, отчёты с печатью и
выгрузкой в Excel/Word, архивирование/восстановление, обновление программы
и журнал логирования.

**Полное руководство по установке и настройке — в файле [INSTALL.md](INSTALL.md).**

## Быстрый старт

```sh
pip install -r requirements.txt
./run.sh                # порт по умолчанию 8080 (порт 5000 занят другой программой)
```

Открыть в браузере: `http://<IP-сервера>:8080` — вход `admin` / `admin`.

Другой порт: `./run.sh --port 8090` или `PORT=8090 ./run.sh`.
Если порт занят — приложение автоматически подберёт ближайший свободный.

## Основные страницы

| Адрес | Назначение | Доступ |
|---|---|---|
| `/journal/opeka` и др. | журналы приказов + PDF-сканы | по ролям (+ Куратор, Администратор) |
| `/employees` | сотрудники, логины, роли | Администратор |
| `/order_types` | виды приказов | все |
| `/reports` | 3 отчёта: печать / Excel / Word | Куратор, Администратор |
| `/service` | архивация, восстановление, обновление | Администратор |
| `/logs` | 📜 журнал логирования (просмотр и скачивание) | Администратор |
| `/profile` | «Моя учётная запись»: самостоятельная смена пароля | все сотрудники |

Файл журнала: `data/logs/app.log` (ротация 5×2 МБ). Записываются HTTP-запросы,
входы/выходы, неудачные попытки входа, отказы доступа, все изменения данных,
резервные копии, восстановления и обновления.
